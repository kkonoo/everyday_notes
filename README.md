## 냉장고 털이

‘냉장고’ 탭에서 집에 있는 재료를 관리하고, 지금 있는 재료로 만들 수 있는 메뉴를 골라 봐요. 재료는 보관 위치 카드(냉장고·냉동고·실온 등, 위치 카드를 길게 누르거나 설정 › 보관 위치 편집에서 냉장고 2대처럼 직접 추가·이름·그림·순서 바꾸기) 안에 칩으로 모여요. 쉼표나 줄바꿈으로 나눠 여러 개를 한 번에 넣고, 칩의 점 색은 재료 종류, 테두리는 양(조금은 꿀색, 다 떨어짐은 점선)이고, 칩을 누르면 바로 아래에서 양(많음·조금·다 떨어짐)이나 종류를 바꾸거나 유통기한·메모를 고쳐요. 칩을 끌어(폰은 길게 눌러) 다른 위치 카드에 놓으면 옮겨져요. 카드 안 칩은 재료 종류(야채·과일·단백질·탄수·섬유질·해산물 등, 설정 › 재료 종류 편집에서 이름·색·순서 바꾸기) 순서로 모이고, 종류 단추를 누르면 그 종류만 진하게 보여요. 종류는 안 고르면 이름으로 짐작해요. 유통기한이 3일 안 남은 재료와 지난 재료는 맨 위에 따로 보이고, 간장처럼 오래 두는 재료는 ‘기본 재료’로 체크하면 접혀 있어요. ‘오늘 뭐 해 먹지’는 식단 › 메뉴·레시피에 재료를 적어 둔 메뉴 중에서 필수 재료가 다 있는 메뉴(지금 만들 수 있어요)와 1–2개만 없는 메뉴를 식단의 메뉴·레시피처럼 종류(한식·양식…) → 분류(국·메인…) → 하위분류(찌개…, 눌러서 펼치기)로 나눠 보여 주고, 곧 먹어야 하는 재료를 쓰는 메뉴는 맨 위에 늘 보여요. 메뉴 편집 창의 ‘선택 재료’는 없어도 되는 재료예요. 물·소금처럼 늘 있는 재료는 재고 맨 아래 ‘늘 있는 것’ 카드에, 이름만 다른 재료(달걀 = 계란)는 ‘같은 재료’ 칸에 적어 둬요. ‘만들었어요’를 누르면 오늘 식단에 기록하고 쓴 재료의 양을 한 단계 내리며, 없는 재료는 버튼 하나로 장보기의 ‘살 것’에 넣어요. 재고도 다른 데이터처럼 로그인하면 기기끼리 동기화돼요.

## 결산

가계부 화면의 ‘오늘’ 옆 ‘📊 결산’으로 여는 전체 화면이에요. 고른 해(기본 올해, 올해는 이번 달까지 ‘지금까지 결산’)의 가계부 지출을 카드로 위아래로 봐요: 총지출, 지출 분류별 비중, 가장 많이 쓴 달, 달마다 쓴 돈. 금액은 가계부 화면의 ‘실제’와 같은 규칙(‘매달 같은 금액’은 안 적어도 계획 금액)이고 안 적은 달은 0으로 치지 않고 빼요. 작년 기록이 있으면 총지출 카드에 작년 같은 기간과 비교가 한 줄 붙어요. 데이터가 없는 카드는 건너뛰고, 결산은 데이터를 읽기만 해요. ‘금액 숨김’을 켜면 카드의 금액이 ●●●로 보여요. 12월 1일부터 1월 31일까지는 메인 화면 위에 ‘결산 보러 가기’ 배너가 뜨고, 닫으면 그 시즌엔 이 기기에서 다시 안 떠요.

## 앱 설치

폰의 크롬·엣지(PC도)로 열면 메인 화면 위에 ‘📲 살림노트 앱으로 설치하기’ 배너가 떠요. 누르면 브라우저의 설치 창이 뜨고, ✕로 닫으면 이 기기에선 다시 안 떠요. 이미 설치했으면 안 떠요. 아이폰은 브라우저가 설치 창을 못 띄워서 같은 자리에 ‘공유 › 홈 화면에 추가’ 안내가 떠요(사파리·크롬·엣지, 홈 화면에서 열었거나 카톡 같은 앱 안 브라우저면 안 뜸).

## 노트 불러오기

설정 › 노트 › ‘노트 불러오기’로 .json 파일을 고르면 노트 하나가 더해져요. 지금 데이터는 그대로예요(설정 › 백업 › 불러오기는 데이터 전체를 바꿔요). 파일 모양:

```json
{
  "title": "내 스킬 치트시트",
  "type": "list",
  "sections": [
    { "name": "묶음 이름", "items": [{ "text": "항목 제목", "memo": "눌렀을 때 보이는 내용" }] }
  ]
}
```

`type`은 `list`(목록)·`check`(체크리스트)·`shop`(장보기)이고, 안 적으면 목록이에요. `memo`는 목록에서만 보여요.

## 메모 정리

메모 노트의 ‘편집’ 왼쪽 ‘정리’를 누르면 Claude(Opus 5.5)가 대충 적은 메모를 주제별 ‘## 제목’과 목록으로 정리해 창에 보여 줘요. 고칠 곳은 고친 뒤 ‘바꾸기’를 눌러야 메모가 바뀌고, ‘취소’면 그대로예요. 설정 › 노트 › ‘API 키’에 console.anthropic.com에서 만든 키를 넣어야 하고(claude.ai 구독과 따로, 쓴 만큼 요금), 키는 이 기기 브라우저에만 저장돼요(동기화·백업 파일에 안 들어감). 서버 없이 브라우저에서 바로 Claude API를 불러요.
