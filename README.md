## 냉장고 털이

‘냉장고’ 탭에서 집에 있는 재료를 관리하고, 지금 있는 재료로 만들 수 있는 메뉴를 골라 봐요. 재료는 보관 위치 카드(냉장고·냉동고·실온 등, 설정 › 보관 위치 편집에서 냉장고 2대처럼 직접 추가·이름·그림·순서 바꾸기) 안에 칩으로 모여요. 쉼표나 줄바꿈으로 나눠 여러 개를 한 번에 넣고, 칩을 누르면 바로 아래에서 양(많음·조금·다 떨어짐)을 바꾸거나 유통기한·메모를 고쳐요. 칩을 끌어(폰은 길게 눌러) 다른 위치 카드에 놓으면 옮겨져요. 유통기한이 3일 안 남은 재료와 지난 재료는 맨 위에 따로 보이고, 간장처럼 오래 두는 재료는 ‘기본 재료’로 체크하면 접혀 있어요. ‘오늘 뭐 해 먹지’는 식단 › 메뉴·레시피에 재료를 적어 둔 메뉴 중에서 필수 재료가 다 있는 메뉴(지금 만들 수 있어요)와 1–2개만 없는 메뉴를 보여 주고, 곧 먹어야 하는 재료를 쓰는 메뉴를 위로 올려요. 메뉴 편집 창의 ‘선택 재료’는 없어도 되는 재료예요. 물·소금처럼 늘 있는 재료는 재고 맨 아래 ‘늘 있는 것’ 카드에, 이름만 다른 재료(달걀 = 계란)는 ‘같은 재료’ 칸에 적어 둬요. ‘만들었어요’를 누르면 오늘 식단에 기록하고 쓴 재료의 양을 한 단계 내리며, 없는 재료는 버튼 하나로 장보기의 ‘살 것’에 넣어요. 재고도 다른 데이터처럼 로그인하면 기기끼리 동기화돼요.
